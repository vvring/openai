# 堡垒机系统设计

## 1. 概述
本文档描述了一套面向企业的统一运维堡垒机系统的总体架构、功能模块与关键技术选型。系统需支持 Linux SSH/SFTP/VNC、Windows RDP（含 NLA）协议接入，支持 TLS 安全加固，并覆盖用户管理、权限分配、会话审计、录像存储与回放等核心能力。

## 2. 系统目标
- **安全合规**：集中管理运维访问，支持基于 TLS 的安全传输与操作审计，满足企业合规要求。
- **多协议支撑**：统一代理多种主机访问协议（SSH、SFTP、VNC、RDP/NLA）。
- **精细化授权**：提供灵活的用户/主机授权模型，满足多角色（管理员、审计员、运维员）协作需求。
- **高可用与扩展性**：支持横向扩展与负载均衡，满足大规模接入场景。

## 3. 架构总览
系统采用分层架构，核心组件包括：

1. **访问入口层**
   - 负载均衡：支持 L7 反向代理（如 Nginx/HAProxy）或云负载均衡，接入 HTTPS/TLS。
   - 协议网关集群：
     - SSH/SFTP 网关节点。
     - RDP/VNC 网关节点。
     - 统一认证模块对接。
   - 会话录制代理：负责实时捕获交互数据流并写入存储。

2. **业务服务层**
   - 用户与角色管理服务。
   - 主机资产管理服务。
   - 授权策略/策略评估服务。
   - 会话审计与录像索引服务。
   - 任务调度/运维工具（脚本执行、文件分发可选）。

3. **数据存储层**
   - 关系型数据库（PostgreSQL/MySQL）：存储用户、主机、授权、审计索引等。
   - 对象存储（S3/MinIO）：存放会话录像、文件传输记录。
   - 日志与监控（ELK/EFK、Prometheus/Grafana）。

4. **管理控制台**
   - Web 控制台（前端 Vue/React + 后端 REST/gRPC）。
   - 提供用户管理、主机管理、授权策略配置、会话审计检索与回放等界面。

5. **运维工具与开放接口**
   - RESTful API/GraphQL：供第三方系统集成。
   - Syslog/消息队列：向 SIEM 或告警系统输出安全事件。

## 4. 核心功能设计

### 4.1 用户与角色管理
- 支持本地用户及外部认证（LDAP/AD、SAML、OIDC）。
- 角色模型：
  - **系统管理员**：全局配置、用户/主机管理、策略制定。
  - **审计员**：会话检索、录像回放、操作审计报告导出。
  - **运维员**：按授权访问主机、执行运维操作。
- 支持多因素认证（MFA）。

### 4.2 主机资产管理
- 主机分类（按业务、环境、标签）。
- 支持批量导入（CSV/API）与自动发现。
- 主机凭证管理：支持账号/密码、SSH Key、RDP 凭证；可对接第三方密码保管系统（如 HashiCorp Vault）。

### 4.3 授权模型
- **用户→主机授权**：指定用户/用户组可访问的主机列表及协议权限。
- **主机→用户授权**：主机侧设置允许访问的用户/组，形成双向授权验证。
- 策略维度包括：时间窗、来源 IP、命令黑白名单、文件传输限制等。
- 采用策略引擎（如 OPA）实现灵活的策略编排与审计。

### 4.4 协议支持
- **SSH/SFTP**：基于 OpenSSH/OpenSSH-Server，支持命令审计、文件传输控制。
- **VNC**：通过 VNC Proxy（如 noVNC + WebSocket）实现浏览器内访问；支持会话录像。
- **RDP**：使用 FreeRDP/Guacamole Gateway，强制启用 TLS 和 Network Level Authentication (NLA)。
- **TLS**：所有网关对外暴露接口必须启用 TLS，证书统一由证书管理服务下发和轮换。

### 4.5 会话审计与录像
- 实时抓取会话数据流，生成结构化日志（命令、窗口操作）。
- 录像存储：
  - 文本类（SSH）保存命令及回显。
  - 图形类（RDP/VNC）保存屏幕录制（可采用帧差压缩、H.264 编码）。
- 审计功能：
  - 支持按用户、主机、时间、关键字检索。
  - 支持敏感操作告警（基于规则或机器学习）。
- 录像回放：Web 播放器支持倍速、跳转、关键帧定位。

### 4.6 运维安全控制
- 命令过滤、双人授权、实时监控（旁路查看活跃会话）。
- 操作水印、剪贴板与文件传输控制。
- 支持会话中断、强制下线。

## 5. 技术选型建议
- **后端语言**：Go / Java / Python（原型阶段采用 Python + 轻量级 FastAPI 兼容实现）。
- **网关实现**：
  - SSH/SFTP：基于 `teleport` 或 `gssh`，或自研使用 `go-ssh` 库。
  - RDP/VNC：Apache Guacamole（支持多协议，Web 化访问）。
- **消息总线**：Kafka/RabbitMQ，用于审计日志与异步任务。
- **缓存**：Redis，用于会话状态、限流、分布式锁。
- **容器化**：使用 Kubernetes 部署，实现弹性扩展。

## 6. 安全与合规
- 全链路 TLS，加固加密算法，定期轮换证书。
- 审计日志不可篡改，支持写入 WORM 存储或区块链日志。
- 符合等保、ISO27001 等标准的安全要求（身份鉴别、访问控制、安全审计、入侵防范）。
- 数据脱敏与权限最小化原则。

## 7. 高可用与扩展
- 网关节点多副本部署，支持健康检查与自动切换。
- 数据库主从复制 + 自动故障转移。
- 对象存储多活或跨区域复制，保证录像可靠性。
- 灰度发布与滚动升级策略。

## 8. 运维与监控
- 指标监控：Prometheus 采集 CPU、内存、连接数、协议成功率等，Grafana 展示。
- 日志集中化：Fluentd/Logstash 收集网关、服务日志至 Elasticsearch。
- 告警：接入邮件、短信、IM（企业微信/钉钉）。
- 定期安全基线扫描与漏洞修复。

## 9. 未来规划
- 支持云原生主机与容器资产接入。
- 引入行为分析与 AI 风险检测。
- 自动化运维流程编排（Runbook Automation）。
- 与 CMDB、ITSM、工单系统的深度集成。

## 10. 原型实现
- 本仓库提供的 `app/` 目录实现了一个基于轻量 FastAPI 兼容层的管理后端原型：
  - 提供用户、角色、主机、授权、会话录像等核心数据模型。
  - 自研的请求路由与 `TestClient` 兼容 FastAPI 常用用法，便于在无外网环境中运行与测试。
  - 通过 REST 风格接口模拟用户管理、主机授权、会话启动/结束等能力。
  - 采用 SQLite 默认存储，支持通过 `BASTION_DATABASE_URL` 切换到企业级数据库。
  - 可与未来的协议网关、前端控制台对接，实现完整堡垒机能力闭环。
