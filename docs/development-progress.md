## 已完成功能明细

- **文档**：系统设计文档，涵盖总体架构、核心模块、安全与高可用策略。
- **后端服务**：基于轻量 FastAPI 兼容层 + SQLite 的管理 API，覆盖：
  - 用户、角色、主机、授权的完整 CRUD。
  - 会话生命周期记录与录像索引。
  - 内置验证逻辑确保角色、协议与会话流程的约束。
  - 自研 shim 兼容 `fastapi.testclient`，在离线环境下也可运行端到端测试。
- **权限治理增强**：新增授权目录查询/撤销接口，并在会话启动时强制校验用户状态、授权关系、协议配置与 RDP NLA。
- **运营效率提升**：补充用户/主机详情查询与在线更新接口，可即时冻结账号、调整角色或主机协议设置，并在主机启用 RDP 时强制验证 NLA。
- **资产分类治理**：主机支持维护标签、业务归属及环境信息，API 提供按协议/环境/标签/关键字的过滤能力，方便大规模资产分层管理。
- **录像目录**：新增录像表结构与 API，可查询单条录制及按会话过滤录制记录，保留大小、时长、校验值等属性。
- **审计检索增强**：提供会话详情查询及按用户、主机、协议、时间窗口的过滤能力，同时支持按用户/主机/协议筛选录像记录，提升回溯效率。
- **操作审计事件**：用户、主机、授权的新增/更新/撤销操作支持携带 `performed_by`，通过 `audit_events` 表持久化操作者、动作与上下文，并开放 `/audit-events` 检索接口。
- **列表分页能力**：核心列表接口（用户、主机、授权、会话、录像、审计事件）支持 `limit` / `offset` 参数，便于处理大批量数据并支撑前端分页交互。
- **访问时间窗治理**：新增 `access_windows` 策略表及 `/access-windows` 管理接口，可在授权上绑定允许访问的星期与时间范围，会话启动时将实时校验是否处于许可窗口。
- **主机分组管理**：提供主机分组及成员维护接口，可批量绑定主机、按主机过滤分组列表，并在主机详情返回所属分组，支撑资产整合治理。
- **主机凭据库**：`/credentials` 提供主机凭据登记与轮换管理，保留账号类型、轮换频率、最近轮换时间与启用状态，所有变更写入审计事件。
- **双人审批控制**：授权支持 `requires_approval` 标记，新增 `/access-requests` 申请/审批/拒绝/撤销接口，会话发起时需校验审批状态并支持有效期管理。
- **来源 IP 白名单**：授权新增 `source_cidrs` 配置，会话启动必须携带 `source_ip` 并命中白名单，所有会话审计事件将记录来源地址。
- **命令策略防护**：上线 `/command-policies` 命令策略库，可为授权绑定允许/禁止模式，会话启动时校验 `requested_commands` 并将命令指纹写入会话与审计记录。
- **会话登录指引**：新增 `/sessions/{id}/connections` API，结合主机凭据生成登录命令提示、记录连接成败与失败原因，支撑实际运维登录与审计闭环。
- **协议网关编排**：实现 `protocol_gateways` 与 `host_gateway_bindings` 存储及 CRUD，支持为主机协议绑定网关、记录健康状态，并在会话发起时强制依赖已登记的网关能力。
- **网关登录指引**：主机详情返回已绑定的网关列表，`/sessions/{id}/connections` 会根据网关信息自动生成带 ProxyJump 参数的 SSH/SFTP 命令，确保访问流量经过登记网关并写入审计。
- **测试覆盖**：提供关键授权与会话流程的端到端 pytest 测试样例。
