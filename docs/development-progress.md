# 开发进度跟踪

本文档汇总堡垒机系统的分阶段开发任务及当前状态，便于快速了解原型建设的完成度与后续计划。

## 阶段概览

| 阶段 | 目标 | 状态 |
| --- | --- | --- |
| 1. 架构设计 | 完成总体架构、功能规划与技术选型文档 | ✅ 已完成 |
| 2. 管理后端原型 | 提供用户、角色、主机、授权、会话录制索引等核心 CRUD API | ✅ 已完成 |
| 3. 协议网关集成 | 接入 SSH/SFTP、RDP/NLA、VNC 网关并统一认证审计 | ⏳ 规划中 |
| 4. 前端控制台 | 实现 Web 控制台：用户/主机管理、授权配置、会话审计回放 | ⏳ 规划中 |
| 5. 运维工具与自动化 | 提供批量命令执行、文件分发、运维工单对接等工具 | ⏳ 规划中 |
| 6. 高可用与安全加固 | 引入多副本部署、证书管理、MFA、审计告警等企业级特性 | ⏳ 规划中 |

## 已完成功能明细

- **文档**：系统设计文档，涵盖总体架构、核心模块、安全与高可用策略。
- **后端服务**：基于轻量 FastAPI 兼容层 + SQLite 的管理 API，覆盖：
  - 用户、角色、主机、授权的完整 CRUD。
  - 会话生命周期记录与录像索引。
  - 内置验证逻辑确保角色、协议与会话流程的约束。
  - 自研 shim 兼容 `fastapi.testclient`，在离线环境下也可运行端到端测试。
- **权限治理增强**：新增授权目录查询/撤销接口，并在会话启动时强制校验用户状态、授权关系、协议配置与 RDP NLA。
- **录像目录**：新增录像表结构与 API，可查询单条录制及按会话过滤录制记录，保留大小、时长、校验值等属性。
- **测试覆盖**：提供关键授权与会话流程的端到端 pytest 测试样例。

## 进行中 / 待办事项

- 设计并实现协议网关组件，支持 SSH/SFTP、RDP (NLA)、VNC 接入与 TLS 加固。
- 打通录像采集与回放流程，定义录像存储格式与索引结构。
- 搭建前端控制台原型，支持用户管理、授权配置、录像检索与回放。
- 补充运维安全策略（命令过滤、双人授权、实时监控等）并完善告警链路。
- 规划生产可用的部署方案（容器化、监控、日志、备份）。

## 里程碑与下一步计划

1. **短期（M1）**：完成协议网关 PoC，与现有管理 API 对接，实现 SSH/RDP 会话的认证与审计。
2. **中期（M2）**：交付 Web 控制台最小可用版本，支持资产与授权管理、会话列表与录像回放。
3. **长期（M3）**：完善企业级安全与高可用能力，支持多活部署、全面监控告警及合规审计。
