# ngx_weakpass_guard 插件开发大纲

## 一、项目基本信息
- **项目名称**：ngx_weakpass_guard
- **开发目标**：开发一个支持弱口令检测、防爆破、黑名单拉黑、日志记录的 Nginx 插件
- **适用环境**：
  - Nginx 原生模块（或 OpenResty Lua 模块）
  - 适用于 Web 登录接口的安全增强

## 二、核心功能模块设计
1. **请求捕获模块**
   - 拦截指定路径的请求（如 `/login`），路径可配置
   - 支持从 JSON 或表单中提取 `username`/`password` 字段

2. **弱口令检测模块**
   - 检查是否使用弱口令
   - 内置弱口令字典，支持自定义字典文件
   - 密码复杂度检查（长度、数字、字母、特殊符号等）

3. **用户名检查模块**
   - 支持白名单（跳过检测）与黑名单（直接拦截）

4. **爆破检测模块**
   - 统计登录失败次数，识别暴力破解行为
   - 滑动时间窗口限制，例如 60 秒内最多 10 次
   - 按 IP 与用户名组合计数，阈值可配置

5. **IP 拉黑模块**
   - 将攻击 IP 加入黑名单，可在共享内存中保存
   - 支持黑名单过期
   - 内置拦截逻辑：返回 403、跳转或自定义响应

6. **日志记录模块**
   - 记录 IP、用户名、密码（可脱敏）、UA 和时间戳
   - 日志格式支持 JSON 或纯文本
   - 支持按天分日志，可配置路径
   - 可选远程上报（HTTP API）

7. **配置管理模块**
   - nginx.conf 中直接配置或通过单独文件引用
   - 支持热更新，无需重启

## 三、扩展模块设计（可选）
| 模块 | 功能 |
| ---- | ---- |
| GeoIP | 按国家/区域限制爆破来源 |
| Honeytoken | 设置诱捕用户名，如 `admin_test` |
| 报警模块 | 攻击触发后发送邮件或 Webhook |
| 控制台界面 | 查询封禁 IP、查看统计（可选 Web UI 或 CLI） |
| Lua 支持 | 若使用 OpenResty，可热部署和快速开发 |

## 四、程序结构建议
```
ngx_weakpass_guard/
├── src/
│   ├── core.c             # 主控制逻辑
│   ├── request_parser.c   # 请求体解析
│   ├── weakpass_check.c   # 弱口令匹配逻辑
│   ├── ratelimit.c        # 爆破频率控制
│   ├── blacklist.c        # 黑名单管理
│   ├── logger.c           # 日志输出模块
│   └── config.c           # 配置解析
├── dict/
│   └── weak_passwords.txt # 弱口令词库
├── conf/
│   └── weakpass.conf      # 插件配置文件模板
├── docs/
│   └── README.md
└── Makefile / build.sh    # 构建脚本
```

## 五、开发计划建议
| 阶段 | 目标 | 内容 |
| ---- | ---- | ---- |
| 第 1 阶段 | 最小可运行版本 | 请求拦截、弱口令检测、日志记录 |
| 第 2 阶段 | 增强检测能力 | 黑名单机制、爆破频率识别 |
| 第 3 阶段 | 扩展能力 | GeoIP、IPSet、远程上报、报警 |
| 第 4 阶段 | 易用性提升 | 配置热更新、管理接口或可视化界面 |
